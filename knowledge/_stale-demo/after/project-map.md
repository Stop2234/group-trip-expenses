# Карта проекта: откуда брать данные

Справка нужна, чтобы найти источник данных и не выдумывать маршруты.

**Проверено для версии:** `group-trip-expenses@2.0.0` (package.json).
**Дата проверки:** 2026-10-12.

---

## Как устроен проект

```
React UI  ──HTTP──► REST API (/api/*)  ─┐
                                        ├──► ExpenseService ──► data/*.json
AI-агент ──MCP───► MCP tools (/mcp)    ──┘
```

Оба пути идут через один `ExpenseService` и читают **одно и то же хранилище**.
Поэтому данные, увиденные через REST, совпадают с данными MCP.

- Источник: `README.md` (раздел «Архитектура»), `src/lib/service.ts`
  (`ExpenseService`), `server/index.ts` (сборка приложения).

## Хранилище

- Файл JSON по умолчанию: `data/trip-data.json`; путь переопределяется
  переменной окружения `DATA_FILE`.
- Запись атомарная (временный файл + переименование). Повреждённый файл не
  роняет приложение: он переименовывается в `*.corrupt-<timestamp>`, состояние
  начинается пустое.
- Источник: `server/storage.ts` (`JsonFileStorage.load/save`), `server/index.ts`
  (строка 20).
- Повод перепроверить: появится второе хранилище или сменится формат файла.

> Запись исправлена 2026-10-12 в учебной копии: прежняя формулировка про
> localStorage унаследована от версии 1.0.0 и не соответствует текущему коду.
> См. `../README.md`.

**Что читать, если сервера нет:** сам файл состояния —
`{ "participants": [...], "expenses": [...] }`, суммы в копейках
(`amountKopecks`, `customShares`), ссылки по `id`.

## Backend: порты и запуск

- `npm run dev:server` — запуск backend (tsx, `server/index.ts`).
- Порт по умолчанию **3001** (`PORT`), слушает `127.0.0.1`.
- Источник: `server/index.ts` (строки 19–20, 87–94).
- **В текущей рабочей среде порт 3001 занят другим локальным проектом**
  (проверено 2026-10-12: запрос на `127.0.0.1:3001` отвечает чужим Express-404).
  Поэтому здесь backend поднимается на **3101**, а второй экземпляр с другим
  файлом данных — на **3102**:
  - `http://127.0.0.1:3101` — основной набор данных (`data/trip-data.json`);
  - `http://127.0.0.1:3102` — второй набор (`data/trip-scenario2.json`).
- Повод перепроверить: освободился порт 3001 или сменился номер в логе запуска.

Всегда сверяй адрес с выводом запуска сервера («Сервер запущен: http://…») и
указывай **фактически использованный** адрес в отчёте.

## REST API (только чтение — то, что нужно отчёту)

| Метод | Путь | Что возвращает |
|---|---|---|
| GET | `/api/state` | участники + расходы целиком |
| GET | `/api/summary` | балансы, переводы, общая сумма |
| GET | `/api/settlements` | балансы + переводы + `totalExpensesKopecks` |
| GET | `/api/participants` | участники |
| GET | `/api/expenses` | расходы |

Записывающие маршруты (`POST/PUT/DELETE ...`) **для скилла запрещены**, они
перечислены только для узнаваемости: `POST /api/participants`,
`DELETE /api/participants/:id`, `POST /api/expenses`,
`PUT /api/expenses/:id`, `DELETE /api/expenses/:id`, `POST /api/demo`,
`DELETE /api/trip`.

- Источник: `server/api.ts` (12 маршрутов, строки 34–136).
- Повод перепроверить: добавление или переименование маршрута.

## MCP-инструменты

Endpoint: `POST /mcp` (Streamable HTTP, **stateless**, без API-ключей).
Имя сервера `trip-expenses`, версия `1.0.0` (проверено ответом `initialize`
2026-10-12).

Чтение (разрешены скиллу):

| Инструмент | Что возвращает |
|---|---|
| `list_participants` | участники (id, имя) |
| `list_expenses` | расходы с суммами в копейках/рублях и отформатированной строкой |
| `calculate_settlements` | балансы, переводы, общая сумма |
| `get_summary` | сводка: участники, число расходов, суммы, балансы, переводы |

Запись (**запрещены скиллу**): `add_expense`, `add_participant`,
`remove_expense`, `load_demo`.

- Источник: `server/mcp.ts` (`createToolHandlers`, `registerMcpTools`); список
  из восьми имён сверен реальным `tools/list` 2026-10-12.
- Повод перепроверить: добавление инструмента или изменение схемы.

### Подключение MCP к клиенту OpenCode

В `opencode.json`:

```json
"trip-expenses": { "type": "remote", "url": "http://127.0.0.1:3101/mcp" }
```

Запись добавлена 2026-10-12. Повод перепроверить: смена порта сервера.

**Ограничение, о котором надо помнить:** подключение MCP-сервера читается при
старте сессии. Если в сессии инструментов `trip-expenses` нет — используй REST
(`GET /api/state`, `GET /api/settlements`) и обязательно укажи это в строке
`**Источник данных:**`.

## Порядок выбора источника (для скилла)

1. MCP-инструменты чтения — если они есть в сессии.
2. REST `GET /api/state` + `GET /api/settlements` — если сервер запущен.
3. Файл состояния JSON — если сервера нет.

Любой из трёх путей legitimate: важно назвать его в отчёте.
