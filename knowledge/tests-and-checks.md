## Проверки самого отчёта (инструменты этого задания)

```bash
# 5 требований стайлгайда (оформление)
node tools/check-style.mjs reports/<отчёт>.md [--state data/<состояние>.json]

# арифметика: независимый пересчёт в копейках
node tools/check-numbers.mjs --state data/<состояние>.json --report reports/<отчёт>.md
```

- `check-style.mjs` — порядок разделов, формат сумм, таблица расходов,
  таблицы балансов и переводов, строки источника и контрольной проверки.
  Вывод: `PASS/FAIL` по каждому требованию и `Итог: N/5`; код выхода 0 только
  при `5/5`.
- `check-numbers.mjs` — пересчитывает суммы, доли, балансы и переводы сам
  (целые копейки, без обращения к коду приложения) и сверяет с таблицами
  отчёта. Вывод: `Итог: ПРОЙДЕНА (N/M)`; код выхода 0 при `N/M = M/M`.

Проверки независимы: `check-style` **не** считает деньги, `check-numbers`
**не** проверяет оформление.

- Повод перепроверить: изменится формат таблиц в `STYLE_GUIDE.md` или правила
  расчётов в `knowledge/calculation-rules.md`.

## Как фиксировать результат

Команда считается выполненной, только если она реально запускалась и её вывод
сохранён. Если проверка не выполнялась — так и пиши (см. `AGENTS.md`).
