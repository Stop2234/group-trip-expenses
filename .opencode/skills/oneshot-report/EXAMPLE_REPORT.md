## summary

- **Задание:** one-shot прогон — самостоятельно создать за один запуск агента веб-приложение «Расходы группы после поездки» (участники, расходы, два режима распределения, балансы, взаиморасчёты, демо-данных, README, автотесты), проверить его и выдать отчёт с тремя разделами.
- **Стек:** React ^18.3.1 + TypeScript ~5.6.2 + Vite ^6.0.5 + Vitest ^3.0.5, хранение — `localStorage`, денежные вычисления — целые копейки (integer arithmetic).
- **Окружение (проверено командами):** git 2.53.0, Node v22.23.3, npm 10.9.9, Python 3.14.4; при старте в директории лежал только `opencode.json`.
- **Реализовано:**
  - Управление участниками: добавление, список, удаление с проверкой связи с расходами (`src/components/ParticipantsSection.tsx`, `src/lib/validation.ts`).
  - Управление расходами: добавление, редактирование, удаление; суммы с копейками (`src/components/ExpensesSection.tsx`).
  - Два режима распределения: равномерное (`splitEvenly`) и неравномерное с явными долями (`customShares`) — `src/lib/money.ts`, `src/lib/calc.ts`.
  - Расчёт балансов «заплатил / должен был / нетто» и список переводов, закрывающих долги (`src/lib/calc.ts`).
  - Хранение в `localStorage` с ключом `group-trip-expenses-v1`, сброс данных с подтверждением (`src/lib/store.ts`, `src/App.tsx`).
  - Демо-набор: 4 участника (Егор, Анна, Иван, Мария), 5 расходов, все четыре участника выступают плательщиками, есть частичные распределения (ужин — 3 из 4, кофе — 2 из 4) и одно неравное (`Сувениры`, customShares) — `createDemoState()` в `src/lib/store.ts`.
  - Интерфейс на русском языке с вкладками «Участники / Расходы / Баланс / Взаиморасчёты» (`src/App.tsx`, `src/components/*`, `src/index.css`).
  - Автотесты расчётной и валидационной логики: `src/lib/calc.test.ts`, `src/lib/validation.test.ts`.
  - Документация и игнорируемые файлы: `README.md`, `.gitignore`.
