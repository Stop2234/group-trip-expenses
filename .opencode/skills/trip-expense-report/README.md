# README: скилл trip-expense-report

Переиспользуемый скилл OpenCode, который из данных приложения «Расходы группы
после поездки» собирает итоговый финансовый отчёт в Markdown и проверяет его.

## Установка

Скилл лежит в репозитории — отдельно ставить ничего не нужно.

1. Скопируйте каталог `.opencode/skills/trip-expense-report/` в свой проект
   (или держите его в `.opencode/skills/` того проекта, где работаете).
2. Положите рядом `STYLE_GUIDE.md`, `AGENTS.md`, `knowledge/` и `tools/`
   (они нужны для проверок и фона) — либо поправьте пути в `SKILL.md`.
3. Запустите приложение, чтобы был источник данных:

```bash
npm install
npm run dev:server          # backend, по умолчанию http://127.0.0.1:3001
# если порт занят другим проектом:
PORT=3101 npm run dev:server
```

4. (По желанию) подключите MCP-сервер к клиенту OpenCode — см.
   `knowledge/project-map.md`, раздел «Подключение MCP к клиенту OpenCode».

## Как вызвать

Откройте новый чат OpenCode в каталоге проекта и попросите отчёт, например:

> Составь итоговый отчёт по поездке из http://127.0.0.1:3101 и сохрани в
> reports/report-trip-1.md

Агент подхватит скилл `trip-expense-report` по описанию в frontmatter (составить
отчёт, проверить расчёты, итоги расходов). Вручную на скилл можно сослаться
явно: «используй скилл trip-expense-report».

Вход: источник данных (MCP / REST / файл) и путь для отчёта.
Выход: Markdown-файл по шаблону
`.opencode/skills/trip-expense-report/templates/report-template.md`.

## Проверка результата

```bash
node tools/check-style.mjs    reports/<отчёт>.md --state data/<состояние>.json
node tools/check-numbers.mjs  --state data/<состояние>.json --report reports/<отчёт>.md
```

Первая команда — пять требований оформления (`Итог: 5/5`), вторая —
независимый пересчёт арифметики в копейках (`Итог: ПРОЙДЕНА (N/M)`).

## Состав

| Путь | Что это |
|---|---|
| `.opencode/skills/trip-expense-report/SKILL.md` | сам скилл |
| `.opencode/skills/trip-expense-report/templates/report-template.md` | шаблон отчёта |
| `AGENTS.md` | правила проекта: что можно и что нельзя скиллу |
| `STYLE_GUIDE.md` | ровно 5 проверяемых требований к оформлению |
| `knowledge/` | база знаний: индекс и три справки (по надобности) |
| `knowledge/_stale-demo/` | демонстрация исправления устаревшей записи |
| `tools/check-style.mjs`, `tools/check-numbers.mjs` | проверки отчёта |
| `reports/` | готовые отчёты |
| `protocols/` | протокол сценариев и A/B-эксперимента |

## Ограничения

- скилл работает только на чтение: расходы и участники через него не создаются
  и не правятся, денежные переводы не выполняются;
- при пустых или противоречивых данных отчёт не составляется — скилл запрашивает
  недостающее или останавливается;
- MCP-инструменты видны клиенту только если сервер подключён **на старте
  сессии**; иначе используется REST — об этом обязательно пишется в отчёте;
- одна валюта — рубли; синхронизации между устройствами нет.
